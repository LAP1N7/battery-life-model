## 3. 데이터셋 B (C-rate 효과)

- 실제 내용: 시트 1개, 48셀(F0001~F0155 중), 온도 6수준(0/10/25/30/45/55 C) x C-rate 4수준(0.5/0.75/1.0/1.5) x 반복 2. 열: CF, dR_dch, dR_ch, LLI, LAMpe, LAMne, RMSE. 파일에 설명·단위가 없어 화학 조성, 셀 모델, C-rate의 충/방전 정의, 사이클 수, CF/LLI/LAM의 단위는 확인하지 못했습니다(카탈로그 메모: 상용 리튬이온 셀의 단기 가속 사이클 연구). 값 크기는 %로 보이고(LLI 0.9~7.1), dR_*는 대부분 음수라 부호 규약도 미확인이며, LAMne 하나가 ~1e-14(피팅 경계값)입니다.
- C-rate 효과(온도별 평균 제거 후 Spearman, n=48): LLI 0.35 (p=0.016), LAMne 0.30, LAMpe -0.42, LAM 합 0.09, CF 0.47.
- 저온(<=10 C, n=16)에서는 LLI 0.67, LAMne 0.64, LAM 합 0.51로 C-rate 효과가 뚜렷하고, 고온(>=25 C, n=32)에서는 LLI 0.10, LAM 합 -0.11로 거의 없습니다.
- 방향 판정: C-rate 증가가 LLI를 올림(예), LAMne를 올림(예, 특히 저온), 그러나 LAMpe는 내려가서(rho -0.42) LAM 합 전체는 변화 없음(rho 0.09). '고C-rate -> LAM/도금형 손실 증가' 기대는 음극(LAMne)과 저온에서만 부분적으로 맞고, 전체 LAM에서는 확인되지 않습니다. 단위, 사이클 수, 화학 조성이 불명이라 문헌 기대와의 비교는 방향 수준입니다.

### 메커니즘 서명 검증

1. **저온 + 고충전율 -> 리튬 도금형(용량손실 크고 CE 낮고 저항 증가는 작음)**: **partially supported**. 1.67C vs 0.33C 충전(방전 1C 고정, 같은 T·전압 윈도우) @60 EFC, T<=10 C(n=5쌍): 용량손실 증가 100%의 쌍, 평균 +8.9 %p; 1-CE 증가 100%, 평균 +0.236 %p; 그러나 R10 증가가 평균 +19.6 %p로 용량손실 증가보다 큼(R10이 더 작은 쌍 0%) -> '저항 증가 작음' 부분은 **지지되지 않음**. T>=25 C(n=6쌍)에서는 용량손실 +0.9 %p, 1-CE +0.008 %p, R10 -0.06 %p로 효과가 사실상 저온에 한정됩니다. @400 EFC는 T<=10 C에서 1.67C 쌍이 1개뿐이라 검증 불충분(1.0C 쌍 2개: 용량 +4.8 %p, R10 +7.9 %p). 도금을 직접 확인한 것은 아니고(OCV/ICA/분해 없음) 용량+CE 패턴이 일치할 뿐입니다.
2. **고온/고 SOC 캘린더 -> SEI(용량손실과 저항 증가 동반)**: **supported** (300 d, n=16조건). 온도 rho: 용량 0.56, R10 0.64, HFR 0.75; SOC rho: 용량 0.73, R10 0.49; 용량~R10 0.76. 440 d에서도 같은 결론(용량~R10 0.87, HFR 0.86). 단 R 증가는 40 C와 100 % SOC에서만 뚜렷하고(40 C 평균 R10 13% vs 용량손실 9.9%), 0~25 C 평균(용량손실 6~7 %, R10 -2~+1 %)과 SOC 10/50 % 평균(용량손실 5~7 %, R10 약 0 %)에서는 R10이 거의 늘지 않습니다 -> 이 영역의 손실은 저항 증가 없는 용량 손실(LLI형)로, 'SEI = 저항 동반'은 고온/고 SOC에 한정해서만 맞습니다.
3. **깊은 DoD -> LAM(저항 증가)**: 방향은 지지, LAM 귀속은 **검증 불가**. @60 EFC, 같은 EFC에서 깊은 윈도우(2.5-4.2 V) vs 얕은(3.249-4.092 V) n=16쌍: 용량손실 +7.9 %p(깊은 쪽이 큰 쌍 100%), R10 +8.4 %p(100%); 중간(3.249-4.2 V) 대비 n=15쌍: +4.8 / +2.2 %p. 효과는 저온에서 크고(깊은-얕은: 용량 +10.6, R10 +13.8 %p) 고온에서 작습니다(+5.2, +3.0 %p). @400 EFC도 같은 방향(R10 +20.5 %p). 윈도우가 DoD 외에 하한 전압(2.5 V vs 3.249 V)과 상한 전압도 달라 DoD만 분리되지 않으며, OCV 곡선이 없어 LAM인지 LLI인지 구분할 수 없습니다. M50T에서는 25/40 C에서 같은 방향이 아니었습니다(2절).

## 5. 종합: 방법 간 일관/불일관

**일관**

- 저온(0/10 C) 사이클이 두 데이터셋 모두에서 가장 나쁘고 저항 증가를 동반(M50T 0-100%/10 C, KIT 0/10 C @60/400 EFC). 단 M50T 0-30%는 반대.
- 용량손실은 DM의 LLI와 가장 잘 대응(M50T 잔차 +0.8 %p), KIT에서는 R10/R1s/HFR/1-CE와 rho 0.7~0.96로 같이 움직임.
- 고온·고 SOC 캘린더: 용량손실, R10, R1s, HFR 모두 증가(KIT).

**불일관 / 확인 안 됨**

- 저온 고충전율에서 '저항 증가 작음'은 틀림(저항도 크게 증가). 도금 서명은 용량+CE 쪽만 일치.
- M50T 0-100%/40 C와 0-30%/40 C는 R 순위와 용량/LLI 순위가 3단계 이상 어긋남(순위 폭 3). 0-30% 윈도우에서는 온도 경향이 뒤집힘.
- 25/40 C 사이클(KIT)과 0~25 C 캘린더: 용량손실은 있는데 저항은 안 늘어남 -> 저항 지표만으로는 이 손실을 설명하지 못함.
- 데이터셋 B: C-rate가 LAMpe를 내리는 방향이라 'LAM 증가' 기대와 전체적으로 불일치.
- M50T의 같은 Ah 기준 윈도우 효과(25/40 C에서 0-100% < 0-30%)는 KIT의 '깊은 DoD가 더 나쁨'과 방향이 다름(셀·화학·처리량 정규화가 달라 직접 비교 불가).

## 6. 한계

- DM은 모델 추정치이며 용량 데이터에 제약된 피팅이라 용량과의 일치는 독립 증거가 아님. 불확도는 보고되지 않음(RMSE 파일은 있으나 사용하지 않음).
- 데이터셋마다 셀·화학이 다름(NMC811/Gr-Si 21700, HG2 18650(전극 조성은 이 분석에서 확인하지 않음), B는 미상). 교차 데이터셋 비교는 방향 수준.
- KIT는 OCV 곡선이 없어 ICA/DVA·DM 불가. 모든 KIT 모드 해석은 용량·저항·CE의 간접 증거.
- M50T 데이터 이상치/무릎: 0-100%/10 C 셀 A의 RPT4(2355 Ah)에서 R/R0-1 = 5.1(이웃 점은 0.06~0.16)로 측정 이상치로 보이며 제거하지 않고 두었습니다(Spearman은 순위 기반이라 영향이 작고, 6600/4000 Ah 보간점에는 쓰이지 않음). 0-30% 윈도우의 4셀(A, B, E, F)은 약 8100~9700 Ah 이후 급격한 용량 붕괴(무릎, 용량손실 > 30 %)가 있고 이 구간에서 LAM_PE와 R이 함께 급등합니다. 폐합/풀링 통계에는 이 점들이 포함되어 있고, 공통 처리량 비교(4000/6600 Ah)는 무릎 이전 구간입니다.
- M50T는 단일 C-rate(0.3C/1C)라 C-rate 효과는 B로만 봄. 조건당 2~3셀(0-100%/25 C는 2셀)이고 셀 간 산포가 큼.
- 같은 EFC에서 비교하면 고충전율/저온 셀은 더 짧은 시간에 도달하므로 시간 의존(SEI) 손실과 EFC 의존 손실이 섞임. @60 EFC는 초기 급속 열화 구간이라 체크업 정규화(첫 체크업 기준)와 초기 과도 구간의 영향이 큼.
- CE는 반 사이클 비의 평균(|1-CE|>2 % 제외). 프로파일/캘린더 셀은 CE 없음. EIS HFR/Rpol은 Im 부호 교차 및 1 Hz 실수부로 직접 정의한 지표이며 위상 부호 규약은 데이터에서 추정.
- KIT 펄스 R은 25 C 측정값만 사용(is_rt=1). 저온 측정값(is_rt=0)은 쓰지 않았음.
- 지표 상관은 온도·충전율 공통 요인에 의해 부풀려질 수 있고, 다중 비교 보정은 하지 않음.
